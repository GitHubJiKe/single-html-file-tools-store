# Design Document: GIF Quest (Cyber Neon)

## 1. Aesthetic Direction

- **Tone**: Cyber Neon / Pulsating Modern. A dark, high-energy interface that focuses on the vibrancy of the GIF content.
- **Color Palette**:
    - Background: `#050505` (Deep space black)
    - Surface: `#121212` (Elevated dark surface)
    - Primary: `#7000FF` (Electric Purple)
    - Accent: `#FF007A` (Neon Pink)
    - Success: `#00FFC2` (Cyan)
    - Text: `#FFFFFF` (White) / `#A0A0A0` (Dimmed)

## 2. Typography

- **Title**: `Outfit` - Bold and modern for headings.
- **Body**: `Inter` - Highly legible for labels and UI elements.

## 3. UI Components

- **Search Bar**: Floating glassmorphism input with a neon glow focus state.
- **Masonry Grid**: Variable height cards with zero or minimal padding to maximize image visibility.
- **Interaction Feedback**:
    - Hover: Slight scale up and border glow.
    - Click: Wave ripples or haptic-like scaling.
- **Mobile Drawer**: A slide-up panel for GIF details and actions when a user taps an image.

## 4. Layout

- **Header**: Minimal logo, search icon, and history toggle.
- **Main**: Multi-column masonry grid (2 columns on mobile, 4+ on desktop).
- **Sticky Actions**: Quick-copy button overlaying each card on hover (or long press on mobile).

## 5. Animation (CSS-only)

- Fade-in and slide-up for GIFs as they load.
- Pulse animation for the "searching" state.
- Smooth layout transitions.
