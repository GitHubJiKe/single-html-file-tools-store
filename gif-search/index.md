# GIF Quest (表情包搜索神器)

GIF Quest 是一个极致轻量、基于 Tenor API 的表情包搜索小工具。它专为快速寻找和分享反应动图而设计，采用 **Cyber Neon** (赛博霓虹) 审美风格，兼顾交互体验与视觉表现。

### 核心功能

1. **实时搜索** - 基于 Tenor v1 API，支持中英文关键词联想搜索。
2. **Cyber Neon UI** - 深色背景搭配流光溢彩的霓虹紫色装饰，极具现代感。
3. **流式瀑布屏** - 采用原生 CSS Masonry 布局，针对不同高度的 GIF 进行完美适配。
4. **一键操作** -
    - 支持移动端长按/点击直接复制代码。
    - 提供独立的一键“拷贝链接”与“下载”按钮。
5. **无线加载** - 支持“查看更多”功能，无限搜寻你喜欢的素材。
6. **隐私安全** - 100% 离线运行逻辑，无广告、无追踪，仅在搜索时与 Tenor 建立安全连接。

### 技术详情

- **Tenor API**: 使用 `LIVDSRZULELA` 进行数据交互。
- **架构**: 纯原生 HTML/CSS/JS，无任何第三方渲染框架。
- **图标库**: [Lucide Icons](https://lucide.dev/) (CDN 加载)。
- **字体**: `Outfit` (标题) & `Inter` (正文)。

### 使用提示

- **移动端**: 专为触摸屏优化，拥有巨大的操作靶点。
- **搜索策略**: 建议使用关键词如“哭、开心、点赞、猫咪”等。
- **分享**: 复制后的链接可直接在微信、钉钉等社交软件预览。
