## 📋 工具简介

Image Mark 是一个极致轻量、零配置、本地化的单文件图片标记工具。支持用户上传本地图片，并在画布上自由添加文字、Emoji 等元素，支持调整样式并一键高质量导出。

---

## 🎯 核心功能

### 功能列表

1. **本地图片加载** - 支持点击上传、拖拽导入及剪贴板粘贴（Ctrl+V）。
2. **文字标记** - 支持添加多行文字，调整颜色、字号。
3. **Emoji 插入** - 集成常用 Emoji 面板，一键点击添加。
4. **元素交互** - 支持对添加的元素进行自由拖拽、选中状态反馈、删除操作。
5. **图片旋转** - 支持 90° 步进旋转背景图片，并自动调整已添加元素的位置。
6. **高质量导出** - 将编辑后的画布导出为原图分辨率的 PNG 格式。

### 功能详情

- **Canvas 渲染引擎**
    - 实现方式：基于原生 Canvas 2D API，使用 `requestAnimationFrame` 驱动渲染循环。
    - 用户交互：实时预览所有编辑操作，支持选中态边框提示。
- **多维度导入**
    - 实现方式：集成 File API 和 Clipboard API。
    - 用户交互：点击界面中央的 Drop Zone 或直接在页面粘贴图片即可开始。

## 🔧 技术细节

### API 使用

- **Canvas API**: `drawImage`, `fillText`, `measureText`, `strokeRect` 等。
- **File & Drag API**: 处理本地文件读取。
- **Clipboard API**: 监听 `paste` 事件实现截图直接导入。

### 性能优化

- **渲染限制**：仅在状态改变或鼠标移动时触发重绘。
- **High-DPI 适配**：自适应视网膜屏幕，确保文字与 Emoji 边缘清晰。
