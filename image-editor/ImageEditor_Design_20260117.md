# Image Mark: 视觉设计方案

| 属性           | 内容                             |
| :------------- | :------------------------------- |
| **设计风格**   | **Studio Dark (暗雅工作室)**     |
| **核心关键词** | 专业感、流畅性、沉浸式、极简主义 |
| **日期**       | 2026-01-17                       |

## 1. 设计愿景与调性定义

**愿景**：消除工具与创作之间的阻碍，提供一个“如同呼吸般自然”的图片标记环境。
**调性**：

- **色调**：深邃而不压抑的碳灰色调，配合高饱和度的功能性点缀色（电光蓝 Electric Blue）。
- **质感**：采用微量毛玻璃（Glassmorphism）与细腻的内阴影，增加界面的层次感与空间深度。

## 2. 设计规范系统 (Design System)

### 2.1 色彩体系 (Color Palette)

- **Background**: `#0F172A` (深海军蓝黑，提供沉浸感)
- **Surface**: `#1E293B` (卡片/侧边栏背景)
- **Primary**: `#38BDF8` (电光蓝，关键操作按钮)
- **Accent**: `#F472B6` (柔粉色，用于 Emoji 或特殊标记状态)
- **Text**: `#F1F5F9` (标题), `#94A3B8` (辅助描述)

### 2.2 排版逻辑 (Typography)

- **Heading**: `Outfit`, `System-UI` (无衬线几何体，展现现代感)
- **Body**: `Inter`, `system-serif` (高辨识度，注重长文本阅读体验)
- **Size**: 14px (主体), 12px (辅助), 24px (标题)

### 2.3 布局 (Layout)

- **中央工作区**：占据 80% 视野，背景为中灰色棋盘格（Alpha 背景提示），图片居中。
- **配置侧边栏**：右侧悬浮或固定，控制文字大小、色值、Emoji 选择。
- **极简顶栏**：显示 Logo 与导出按钮，采用半透明毛玻璃效果。

## 3. 核心视图视觉解析

- **导入态**：界面中央显示虚线边框的 Drop Zone，带有细腻的光晕动画，暗示“可拖拽”。
- **编辑态**：选中 Canvas 上的元素时，元素周围出现极细的电光蓝选框，并带有四个圆型旋转/缩放手柄。
- **导出态**：点击保存时，按钮产生波动点击特效（Ripple Effect），并显示一个极短的进度条。

## 4. 关键交互与微动画说明

- **Hover States**：所有的按钮在悬停时略微放大（Scale 1.05），并伴随背景色微光流转。
- **Layer Switching**：切换选中的文字/图片时，侧边栏属性面板通过透明度与位移的协同（Fade-in + Slide-up）平滑呈现。
- **Canvas Interaction**：拖拽元素时，增加轻微的物理惯性动效，让操作富有手感。

## 5. 前端开发实施建议

- **布局实现**：强制使用 `Flexbox` 和 `Grid` 的组合，侧边栏使用 `position: sticky` 或 `fixed`。
- **Canvas 优化**：使用 `requestAnimationFrame` 处理拖拽渲染，确保 60FPS 的流畅度；支持 `devicePixelRatio` 缩放以应对视网膜屏幕（Retina）。
- **特效**：CSS 滤镜 `backdrop-filter: blur(12px)` 用于毛玻璃；`transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)` 用于全局动效。
